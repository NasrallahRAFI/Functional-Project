# V4 scope

The owner has proposed a new audio dataset combining three registered original sources. A new corpus and training/validation/test split will be defined. Exact membership, label mapping, calibration-file handling, segmentation, recording/event groups, processing, size budget and scoring protocol are not established by the folder migration.

V3 remains an independent study with its existing membership and split. Existing test-use history must be recorded for source material carried into V4. A new version name or split does not establish unseen data.

All V4 outputs belong to their registered V4 paths. No result, normalization file, threshold or runtime package is inherited by directory linkage. The existing implementation is a code baseline only.
