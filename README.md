# Drone acoustic detection project

This repository uses independent study branches and a shared external artifact store.

Start with STUDY.md when working in a study checkout. The project catalog is docs/PROJECT.md in the repository/ checkout. That catalog registers historical V1 and V2 studies, active V3, and the V4 scope scaffold.

Code and documents are versioned by Git. Large sources, prepared data, runs, releases, and private runtime state are stored outside Git under the enclosing project folder. See docs/governance/STORAGE.md and docs/governance/VERSIONING.md.
