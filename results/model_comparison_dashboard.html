Matched groups

Paired intervals answer the closer question.

Each interval bootstraps the same held-out groups for both models and reports ΔF1 for the left model minus the right.

Intervals crossing zero do not establish a difference. They also do not prove equivalence. A comparison is stronger evidence when its paired interval excludes zero.

Read the result in context

Limits and reproducibility.

This report preserves the decision trail so that strong scores are read with their limits attached.

Known limits

  • Validation was reused for model and threshold selection, so validation performance is optimistic.
  • The drone-positive set covers only two drone models; broad generalization is unproven.
  • Some negative clips may be confounded by recording artefacts.
  • The CNN and clean control have overlapping individual intervals. Use the paired interval above; no equivalence test was run.
  • Group bootstrap intervals describe variation across the 247 represented groups, not new sites or devices.
