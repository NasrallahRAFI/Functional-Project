# Study workspace rules

Read STUDY.md and the authoritative documents it names before changing code. The root layout is documented in repository/docs/PROJECT.md (relative to the enclosing ML Course Project folder).

The owner authorized the storage/workspace restructuring on 26 November 2026. This supersedes historical folder-location instructions only; scientific decisions, source membership, splits, frontend identities, model selections and test-access rules remain bound to their study records.

Never change another study's files through a junction. Existing `data`, `results`, `runtime`, and `archive` paths are compatibility views; see the migration registry for their targets. V2 paths exposed to V3 are registered baseline dependencies and must not be regenerated from V3. Use new run directories for new executions; preserve old run names and records. Set DRONE_AUDIO_DATASET_ROOT to the registered Al-Emadi source for raw-audio work.

Historical reports may contain the machine paths used when they were created. Preserve them as evidence. Record a path relocation separately instead of rewriting hashes or frozen records. Keep downloads, audio, model weights, private recordings, browser profiles, caches, environments, and local path configuration out of Git.

The owner's website build standard and GitHub publishing preference continue to apply. Read the parent AGENTS.md for those requirements.
